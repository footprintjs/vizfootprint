# Agent routing integration

The fixture wires the real development-only host scorer and decision function
to Viz's own port. The old route body remains here only as an equivalence
reference; the library contains neither that body nor a vendor adapter.

The original five route cases and five real mock-Agent attribution cases stay
intact. Additional tables compare old/new answers over object and JSON-decoded
fixtures, scorer traits, incumbent positions, policy overrides and numeric
evidence. Non-finite numbers are represented symbolically in saved fixtures.
Providers remain mocked; no model, network retry or timer is needed.
