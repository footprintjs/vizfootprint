# Shared domains on a stack

The feature door exports one pure assessment. A bound channel declared shared with no folded domain refuses the stack in words; a shared axis needs a domain even for a one-layer stack. The sentence quotes the channel and layer but does not guess whether the missing span came from empty rows, silence, an unplaceable value or a failed read.

The renderer supplies its actual axis-channel mapping: this module does not restate bar/category or count/y rules. Only channels actually bound by a layer are assessed. Unbound unfolded entries are still filtered by the previous whole filter; absent, independent and fully folded entries preserve the former picture. Plain views keep their own-extent handling, outside this stack-only rule.

The advice is to give the named channel values the shared axis can place. A caller supplies table data and bindings; a definition cannot supply a folded domain (its domain option is only `'union'`). For example, populate an empty numeric table with placeable axis values while keeping its shared `bounds: [0, 10]`: the host then folds the domain. Real source/store/frame/renderer tests follow that advice for all five marks on y and for line, point and histogram x, using real bins and box-summary rows and checking visible marks. Existing mark/scale refusals remain after this gate; another true refusal can be the next result. No query, parser, recording, gesture, timer or retry is added. Tests exercise the public renderer and source/store/frame door, followed advice, updates and the pure boundary.
